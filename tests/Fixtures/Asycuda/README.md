# ASYCUDA observed contract fixture

`observed-export.json` is derived from the user-provided `export (11).json`, confirmed as a direct ASYCUDA file export.

The source copy contains inline `//` annotations and is not strict JSON. Only those trailing annotations were removed to create this fixture. Personal names, addresses, contact details, and the consignee operator code were anonymized; their JSON types and string shapes were retained. The observed item UUID and its container references, arrays, nulls, codes, dates, and numeric values were preserved. No ASYCUDA field was renamed or structurally normalized.

This fixture documents one observed export only. It does not establish a formal ASYCUDA schema or contract version.
